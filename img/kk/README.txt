Пасхалка: если игрока зовут «Змеючка», клик по его имени в партии показывает всем в комнате случайное фото из этой папки.

Как добавить фото:
1. Положите сюда картинки (jpg, png, webp, gif) с любыми именами из латинских букв и цифр.
2. Запустите из папки игры:  py tools/make_kk_list.py   — он запишет список файлов в img/kk/list.json.
   (Можно обойтись без скрипта: назовите файлы 1.jpg, 2.jpg, 3.jpg … подряд, без пропусков.)
3. Залейте папку img/kk на GitHub вместе с остальными файлами.
